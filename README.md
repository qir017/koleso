# Coleso — менеджер вставок текста

Резидентная утилита для Windows: по **двойному клику средней кнопкой мыши
(колёсиком)** у курсора открывается радиальное меню в стиле GTA 5, из которого
в один клик вставляется заранее заготовленный текст. Секторы можно оформить
картинками-фонами, а каждому колесу — свою тему.

Одиночный СКМ не блокируется и работает в приложении как обычно.

## Управление

| Действие | Результат |
|---|---|
| **СКМ ×2** (двойной клик колёсиком) | Открыть колесо у курсора |
| **Скролл** вверх/вниз | Выбор сектора (по часовой / против) |
| Движение мыши | Выбор сектора курсором (как в GTA) |
| **ЛКМ** | Вставить выбранный текст (Ctrl+V) в активное окно |
| **ПКМ** | Следующее колесо (с индикатором «2 / 3») |
| **СКМ** повторно | Закрыть без вставки |
| Клик мимо колеса | Закрыть, клик проходит в приложение |
| Клик в центре без выбора | Отмена |

Текущий буфер обмена сохраняется и **восстанавливается** через ~0.7 с после вставки.

## Настройки

Окно настроек: двойной клик по значку в трее (у часов) или ПКМ по значку → «Настройки».

- **Колёса** — создание/удаление, название и **тема оформления**: у каждого колеса
  своя тема (первое — «Неон», второе — «Золото» и т.д.).
- **Темы** — встроенные: Тёмная, Светлая, Неон, Золото, Лес, Киберпанк.
- **Секторов** — от 4 до 12 для каждого колеса (ползунок).
- **Тексты секторов** — редактируются в списке; порядок кнопками «Выше/Ниже».
- **Картинки секторов** — у выбранного сектора отдельная рамка с превью:
  - **«Из буфера»** — вставить картинку, которую не надо скачивать: скриншот
    (Win+Shift+S), «Копировать картинку» в браузере, файл из Проводника.
    Картинка из буфера сохраняется в `%APPDATA%\Coleso\images\`;
  - **«Обзор…»** — выбрать файл (png, jpg, bmp, gif, tiff);
  - **✕** — убрать картинку; справа — превью.
- **Отправка картинки** — при выборе сектора с картинкой в активное окно
  уходит **картинка** (Ctrl+V, форматы «картинка» + файл-вложение — её примут
  и мессенджеры, и Paint), а не текст; текст вставляется, только если картинки нет.
- Картинка также служит **фоном сектора** на колесе и показывается
  **обрезанной** — только то, что уместилось (как `background-size: cover`).
  Путь к файлу хранится в `config.json`; если файл удалить — сектор останется
  без картинки.
- **Общие**: автозапуск с Windows, восстановление буфера, подсказки на колесе,
  размер колеса (радиус 150–300), исключения СКМ.
- **Исключения СКМ** — процессы через запятую (например `chrome.exe, game.exe`),
  где средний клик работает как обычно, а колесо не открывается.
- Кнопка **«Показать колесо»** — демо-просмотр без вставки.

Конфиг хранится в `%APPDATA%\Coleso\config.json`.

## Запуск с Windows

Приложение само прописывает себя в автозапуск
(`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) при первом старте.
Отключить: галочка в настройках или пункт меню трея «Запускать с Windows».

## Сборка / публикация

```bash
cd Coleso
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true -p:SelfContained=false -o ../publish
```

Готовый exe: `publish/Coleso.exe` (~210 КБ, требует установленный .NET 9 Desktop Runtime).

## Известные ограничения

- Не работает вставка в приложения, запущенные **от администратора**, если Coleso
  запущен без прав администратора (ограничение Windows UIPI).
- В полноэкранных **эксклюзивных** играх оверлей может не отображаться
  (в borderless/windowed — работает).

## Технологии

C# / WPF (.NET 9), WinForms-трей, глобальный хук `SetWindowsHookEx(WH_MOUSE_LL)`,
вставка через `SendInput` (Ctrl+V), DPI-aware на каждый монитор.
